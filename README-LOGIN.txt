LOGIN ADMIN
===========
1. Jalankan supabase-setup.sql di Supabase SQL Editor.
2. Supabase > Authentication > Users: pastikan ada user:
   admin@admin.mudamas.local
3. Pastikan user tersebut berstatus Confirmed.
4. Login website memakai username: admin dan password yang Anda set di Authentication.

Catatan: website hanya menggunakan Publishable Key. Secret Key tidak dimasukkan ke file frontend.
